Markdown 怎么发到钉钉？保留文字、表格和图片

解释钉钉粘贴 Markdown 和图文时图片丢失的原因，以及 md2chat 的 macOS 原生图文复制和 Windows、网页限制。

直接回答

用 md2chat 桌面版粘贴 Markdown，在预览区点击钉钉图标，再到钉钉输入框粘贴。普通文字保留为可编辑文字，表格、代码、公式和 Mermaid 图转成图片。macOS 钉钉使用专用图文剪贴板结构，M 系列 Mac 已实测文字、图片、文字的顺序。

为什么直接粘贴 Markdown 没有表格？

聊天输入框与 Markdown 编辑器的渲染规则不同。发送竖线表格源码，不代表客户端会解析成表格。md2chat 将表格渲染为 PNG，与前后的文字按原文顺序组合。

为什么网页看得见图片，钉钉却丢了？

浏览器复制通常写入 text/html 与 text/plain。HTML 中包含图片引用，只能证明剪贴板有引用，不能证明目标应用会读取它。macOS 桌面版为钉钉补充原生图文格式，网页无法做到同样的原生格式写入。

Windows 和网页版能保证一次粘贴吗？

不能。Windows 与网页目前使用标准图文，尚未适配 Windows 钉钉专有格式，图片可能被忽略。不要把预览正常或复制成功当成发送成功，请在聊天框核对。

排查图片丢失

展开编辑器下方的剪贴板排查，点击读取当前剪贴板。记录操作系统、应用版本、目标客户端版本、复制入口，以及报告中的格式和图片数量。使用不含工作信息的示例反馈，报告不会包含正文和图片地址。
