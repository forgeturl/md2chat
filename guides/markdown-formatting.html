Markdown 表格、代码、公式和 Mermaid 转聊天图文

了解 md2chat 如何处理 Markdown 标题、列表、链接、表格、语法高亮代码、LaTeX 数学公式及 Mermaid 流程图。

内容核对日期：2026-10-18

支持哪些 Markdown？

支持标题、粗体、斜体、删除线、编号列表、嵌套列表、任务列表、引用、链接、分隔线、表格和图片。输入中的原始 HTML 按文字处理，不能执行脚本。

表格与代码

聊天模式把表格变成清晰图片，邮件模式保留 HTML 表格。代码块按语言进行语法高亮，长行折行，长代码分成多张图片；未知语言按原文排版。

公式与 Mermaid

支持常见行内与独立 LaTeX 数学公式，以及 mermaid 代码块。公式与图表在本机渲染成 PNG，纯文本备用格式保留源码。表格单元格中的公式暂保留源码；不支持外部资源或自定义 Mermaid 配置。

一个可以直接试的例子

用读书会安排做测试：开头写“周六见”，中间插入包含“自由阅读 / 20 分钟”和“交流讨论 / 30 分钟”的两列表格，末尾写“记得带书”。复制后核对开头、表格图片、结尾是否都在，再发送。

操作步骤

  1. 从 Markdown 或 AI 工具复制内容，粘贴到 md2chat。
  2. 核对预览中的文字、表格图片与末尾内容。
  3. 按目标平台复制，并在自己的聊天草稿检查顺序和图片。
