钉钉、微信、飞书、企业微信与邮件的图文复制兼容性

md2chat 各平台复制入口、原生与标准 HTML 的区别，以及飞书、企业微信、邮件尚未实测的兼容性边界。

复制目标有什么不同？

钉钉入口在 macOS 桌面应用中写入专有图文格式。微信、飞书、企业微信入口写入标准 HTML 和纯文本，不写入钉钉专有格式。邮件入口保留可编辑 HTML 表格，复杂公式和图表仍为图片。点击图标只复制，不会自动发送消息。

已经验证的范围

macOS M 系列上的钉钉原生文字、图片、文字粘贴已验证。Windows 安装包构建与剪贴板生成不等于 Windows 钉钉验收。微信已有用户粘贴成功反馈，但仍需按当前客户端版本确认。

飞书和企业微信

提供实验性的标准图文入口，尚未完成飞书及企业微信客户端验证。不要求用户为开发安装这些客户端；但没有实际粘贴证据之前，不会宣传为完整适配。飞书网页版验证也不能替代桌面版验证。

邮件图片能随邮件一起发出去吗？

邮件入口生成带内联样式的 HTML，表格可编辑。图片是内嵌 data URI，一些邮件编辑器或收件客户端会去除它。复制成功不等于邮件发送后图片可见，需要在具体邮箱中做草稿与收件验证；当前没有生成 CID 附件邮件。

内容与隐私

转换在本机进行，不需要账号，不向 md2chat 服务器上传正文或图片，也不持久化保存编辑器输入。远程图片会请求原来源；钉钉原生复制所需图片缓存在本机。剪贴板及已发送消息由操作系统和目标应用管理。
