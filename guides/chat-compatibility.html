钉钉、微信、飞书、企业微信与邮件的图文复制兼容性

md2chat 各平台复制入口、企微分段复制、原生与标准 HTML 的区别，以及已实测范围和客户端兼容性边界。

复制目标有什么不同？

钉钉入口在 macOS 桌面应用中写入专有图文格式。Mac 飞书写入原生编辑图文，先展开富文本输入框再一次粘贴；Windows 飞书以及微信入口写入标准 HTML 和纯文本，网页版已禁用钉钉、飞书复制；企业微信有图时打开分段面板，按顺序分别复制纯文字和 PNG，纯文字可直接复制。邮件入口保留可编辑 HTML 表格，复杂公式和图表仍为图片。复制不会自动发送消息。

已经验证的范围

macOS M 系列上的钉钉原生文字、图片、文字粘贴已验证。macOS 企业微信 5.0.12（70798）草稿中已验证独立 PNG 与前后文字可混排，文字可编辑；新版分段面板已完成网页 5 段、桌面 3 段实际粘贴，未发送消息。Windows 安装包构建与剪贴板生成不等于客户端验收。微信已有用户粘贴成功反馈，仍需按当前版本确认。

企业微信为什么需要分段？

在当前 Mac 企业微信中，HTML 加纯文本只保留文字，PNG 加 HTML 和纯文本只保留图片，不能靠一次整段复制保住图文。网页和桌面改为逐段复制、依次粘贴，文字仍可编辑，粗体等强调样式不保证保留。托盘转换图文时打开独立分段面板，保留主编辑器输入。Windows 企业微信和发送后效果未验证。

飞书

Mac 桌面版先展开飞书富文本输入框，再一次粘贴文字、图片混排；本机已实测两张图片与前中后文字、粗体、斜体和删除线保留，并由用户发送确认。普通输入框可能丢图。网页版暂不开放飞书复制，请使用桌面版（推荐 Mac）；Windows 仍使用实验性的标准图文，尚未完成对应客户端验证。

邮件图片能随邮件一起发出去吗？

邮件入口生成带内联样式的 HTML，表格可编辑。图片是内嵌 data URI，一些邮件编辑器或收件客户端会去除它。复制成功不等于邮件发送后图片可见，需要在具体邮箱中做草稿与收件验证；当前没有生成 CID 附件邮件。

内容与隐私

转换在本机进行，不需要账号，不向 md2chat 服务器上传正文或图片，也不持久化保存编辑器输入。远程图片会请求原来源；钉钉和 Mac 飞书原生复制所需图片缓存在本机。剪贴板及已发送消息由操作系统和目标应用管理。
