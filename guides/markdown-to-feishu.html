Markdown 怎么发到飞书？文字与图片一次粘贴

使用 md2chat 桌面版将 Markdown 转为飞书图文，了解展开富文本输入框的步骤、Mac 实测与 Windows 待验收范围。

内容核对日期：2026-10-18

直接回答为什么普通输入框可能丢图？Mac 与 Windows 的验证有什么区别？如何判断本次粘贴完整？操作步骤可复现的公开示例实现与验证依据

直接回答

下载 md2chat 桌面版，粘贴 Markdown 并核对预览，点击飞书复制；先展开飞书富文本输入框，再粘贴。普通文字保持可编辑，表格、代码、公式与图表转为图片。网页版不提供飞书复制。

为什么普通输入框可能丢图？

飞书普通聊天框与展开后的富文本编辑区可能采用不同的剪贴板导入路径。已验证的 Mac 流程使用原生编辑 fragment；标准 HTML 中有图片，不代表飞书会导入它。

Mac 与 Windows 的验证有什么区别？

Mac 已有两张图片、前中后文字及粗体、斜体、删除线的粘贴和用户发送确认。Windows 根据飞书 7.51.0.45 编辑器样本生成原生 fragment 与本机 PNG 引用；样本读取和源码实现不能代替新构建粘贴验收。

如何判断本次粘贴完整？

先用下面的公开示例核对开头、表格图片和末尾文字，再尝试修改普通文字。若图片缺失，确认已展开富文本输入框，并记录系统、md2chat 和飞书版本。不要仅根据“复制成功”判断发送结果。

操作步骤

  1. 打开桌面版，将下面示例粘贴到输入区，等待预览完成。
  2. 点击飞书复制，切换到自己的飞书聊天草稿。
  3. 展开富文本输入框，再按 ⌘V 或 Ctrl+V。
  4. 核对文字、表格图片、末尾文字的顺序；确认后自行发送。
