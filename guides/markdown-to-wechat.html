Markdown 转微信图文：文字可编辑，表格转图片

使用 md2chat 将 Markdown、彩色代码、公式和表格转换成微信图文，了解标准 HTML 复制的适用范围和图片排查步骤。

使用方法

在左侧输入 Markdown 或粘贴图文，确认右侧预览后点击微信图标，再到微信聊天输入框粘贴。md2chat 写入标准 HTML 图文和纯文本，保留文字、图片、文字的顺序，不把整篇文章变成一张长图。

哪些格式会变成图片？

表格、带颜色的代码块、数学公式和 Mermaid 图会渲染成图片；标题、列表、引用、粗体等转换成聊天可读的文字和强调。原图保留在对应位置，无法读取图片时会提示补图。

是否适用于所有微信版本？

不能保证。剪贴板导入由微信客户端处理，浏览器、系统和客户端版本都会影响结果。已有用户反馈标准 HTML 图文可在微信粘贴，但不能据此推断所有版本、所有平台均兼容。发送前应核对图片和末尾文字。

文字仍能编辑吗？

普通段落仍然是文字，可以在目标输入框中修改。代码和表格中的文字属于图片，不可直接在聊天框中编辑；可返回 md2chat 修改源文再复制。

操作步骤

  1. 从 Markdown 或 AI 工具复制内容，粘贴到 md2chat。
  2. 核对预览中的文字、表格图片与末尾内容。
  3. 按目标平台复制，并在自己的聊天草稿检查顺序和图片。
