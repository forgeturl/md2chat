Markdown 怎么发到企业微信？按顺序保留文字与图片

企业微信图文使用分段复制：每段分别粘贴文字或 PNG，保留 Markdown 表格与前后文字，附 Mac 输入框验证依据。

内容核对日期：2026-10-18

直接回答为什么不能一次复制整篇？网页版和桌面版都能分段吗？已验证到什么范围？操作步骤可复现的公开示例实现与验证依据

直接回答

在 md2chat 中粘贴 Markdown，点击企微。内容有图时会打开分段面板，按面板顺序逐段复制并立即粘贴到同一个企微草稿。每段是纯文字或一张 PNG，普通文字仍可编辑。

为什么不能一次复制整篇？

当前 Mac 企业微信实测中，HTML 加纯文本只保留文字，PNG 加 HTML 和纯文本只保留图片。分段复制是为保留图文顺序而采用的操作方式，不承诺一次粘贴混排。

网页版和桌面版都能分段吗？

两者都有分段面板。网页版需允许浏览器写入剪贴板；桌面托盘可打开独立面板。面板只标记已复制，不会判断你是否已经粘贴，也不会自动发送。

已验证到什么范围？

macOS Apple Silicon、企业微信 5.0.12（70798）草稿中，已验证网页 5 段含 2 张图片、桌面 3 段含 1 张图片，顺序完整且文字可编辑。测试未发送消息；Windows 企微、其他版本及发送后结果仍待分别确认。

操作步骤

  1. 粘贴示例，确认预览中有开头、表格图片和结尾。
  2. 点击企微，复制第 1 段文字，立即粘贴到自己的草稿。
  3. 依次复制、粘贴下一张 PNG 和后续文字，中途不要复制其他内容。
  4. 检查完整顺序和图片数量，再自行发送。
