AI 回答都一定是 Markdown 吗？

不一定。Markdown 是 AI 工具常用的内容表达方式：标题、列表、表格、代码块都可以用它组织。DeepSeek、Codex、Cursor、ChatGPT、Claude 等工具中的 Markdown 内容可以作为 md2chat 输入；实际输出随提示、模式和工具而变，也可能是纯文本、JSON 或文件。这里列举的是内容来源，不代表 md2chat 与这些产品有官方集成或已逐一完成复制链路测试。

为什么 AI 界面里整齐，复制后却变了？

AI 界面可以把 Markdown 渲染成标题、表格和代码。复制按钮和选中文字复制，可能给出不同的剪贴板格式；接收应用也有自己的解析规则。Cursor 的官方更新说明已介绍将 Agent 回复中的 Markdown 表格复制为富表格，纯文本目标则仍得到 Markdown。因此不能认为所有 AI 内容复制后都会丢格式。

怎么用 md2chat 转换？

从 AI 工具中复制 Markdown，粘贴到 md2chat 左侧，检查右侧预览。普通段落、列表和 ✅ / ⬜ 待办仍为可编辑文字；表格、代码、公式和 Mermaid 图转成图片。确认顺序后，按微信、钉钉、飞书、企微或邮件入口复制，再到目标输入框粘贴。无需连接 AI 账号，也不会读取你的 AI 聊天记录。

公式、图表或图片要注意什么？

公式需要保留 LaTeX 源码，Mermaid 需要保留 mermaid 代码块。如果来源只复制了渲染后的文字、丢失了公式源码或图片，md2chat 不能自动恢复缺失内容。请先核对预览，必要时补充原始 Markdown 或图片。

这些 AI 工具都已经兼容测试了吗？

本页说明 Markdown 来源与转换方法，不是 AI 工具兼容性测试表。实际粘贴效果还取决于目标客户端：Mac 钉钉有已验证的原生图文格式，企微有图时逐段复制粘贴，其他范围请看平台兼容性指南。复制成功和预览正常不代表发送后也完整。

操作步骤

  1. 从 Markdown 或 AI 工具复制内容，粘贴到 md2chat。
  2. 核对预览中的文字、表格图片与末尾内容。
  3. 按目标平台复制，并在自己的聊天草稿检查顺序和图片。
