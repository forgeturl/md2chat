Convert Markdown to WeChat messages with editable text

Prepare Markdown tables, code and equations as images while keeping ordinary text editable, then verify the result in your WeChat client.

Direct answer

Paste Markdown into md2chat, check the preview, choose WeChat and paste into the chat input. md2chat writes standard HTML and plain text in source order rather than turning the entire message into one screenshot.

Which parts become images?

Tables, code blocks, equations and Mermaid diagrams become images. Ordinary paragraphs and lists remain text. Text inside an image cannot be edited in the destination; edit the source and copy again.

Does this work in every WeChat version?

No universal compatibility claim is made. There is user feedback that standard HTML messages paste successfully, but browser, OS and client versions affect import. Check image count and the final paragraph before sending.

What if the image cannot be read?

Confirm that the original image is available and appears in the preview. A remote server may restrict access. The web editor cannot read arbitrary local file paths; the desktop Markdown workflow can read local images that pass validation.

Step by step

  1. Copy Markdown from your source and paste it into md2chat.
  2. Check the text, table image and final paragraph in the preview.
  3. Choose your destination and inspect the result in your own draft.

A public example

# Weekend book club

Start: see you on Saturday.

| Activity | Duration |
| --- | --- |
| Quiet reading | 20 minutes |
| Discussion | 30 minutes |

End: remember to bring a book.

Check the opening text, table image and closing text in your own draft. Ordinary text should remain editable.
