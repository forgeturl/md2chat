Convert Markdown tables, code, equations and Mermaid to chat images

Learn which Markdown elements stay editable and which become PNG images, with a reproducible table example.

Direct answer

md2chat keeps ordinary text editable and renders complex blocks as images in their original order. It supports headings, emphasis, lists, task items, links, tables, images, code, LaTeX equations and fenced Mermaid diagrams. Raw HTML is treated as text.

Tables and code

Chat destinations receive table images; email keeps editable HTML tables. Code uses syntax highlighting, wraps long lines and may span several images. Unknown languages retain their original text layout. Inline code remains text.

Equations and diagrams

Keep LaTeX source and mermaid code fences. Equations and diagrams render locally to PNG. Equations inside table cells currently retain their source. External TeX extensions, custom Mermaid configuration and external diagram resources are not supported.

Check a minimal example

Use the public sample below. In the chat draft, verify opening text, the table image and closing text, then edit an ordinary word to confirm it remains text. A preview alone is not a destination-client test.

Step by step

  1. Copy Markdown from your source and paste it into md2chat.
  2. Check the text, table image and final paragraph in the preview.
  3. Choose your destination and inspect the result in your own draft.
