How to share Markdown text and images in WeCom

Copy and paste text and PNG segments in order, with the tested Mac WeCom draft workflow and explicit platform limits.

Content reviewed：2026-10-18

Direct answer

Paste Markdown into md2chat and choose WeCom. If it contains images, a segment panel opens. Copy each text or PNG segment and immediately paste it into the same WeCom draft before continuing. Ordinary text remains editable.

Why use several paste operations?

In the tested Mac WeCom client, HTML plus plain text retained only text; PNG plus HTML and text retained only the PNG. Separate copies allow the user to preserve the full order. This workflow does not promise one-paste mixed content.

Web and desktop behavior

Both provide the segment workflow. The web version requires browser clipboard permission. Desktop tray conversion opens its own panel. The panel records copied segments, cannot know whether you pasted them and never sends a message.

Evidence and limits

Mac WeCom 5.0.12 (70798) drafts on Apple Silicon retained five web segments with two images and three desktop segments with one image. Text stayed editable. Those tests did not send messages; Windows WeCom, other client versions and sent results need separate validation.

Step by step

  1. Paste the sample and inspect its opening, table and ending.
  2. Choose WeCom, copy the first text segment and paste it into your draft.
  3. Copy and paste the next PNG and subsequent text in order.
  4. Check the full draft before sending it yourself.

A public example

# Weekend book club

Start: see you on Saturday.

| Activity | Duration |
| --- | --- |
| Quiet reading | 20 minutes |
| Discussion | 30 minutes |

End: remember to bring a book.

Check the opening text, table image and closing text in your own draft. Ordinary text should remain editable.
