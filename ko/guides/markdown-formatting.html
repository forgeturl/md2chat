Markdown 표·코드·수식·Mermaid를 채팅 이미지로

텍스트로 남는 부분과 PNG로 바뀌는 부분을 재현 가능한 표 예제로 설명합니다.

내용 확인일：2026-10-18

바로 답하기표와 코드수식과 도표최소 예제로 확인사용 순서재현 가능한 공개 예제구현 및 검증 기록

바로 답하기

제목·강조·목록·작업 항목·링크·표·이미지·코드·LaTeX·Mermaid를 지원합니다. 일반 문장을 편집 가능한 상태로 유지하고 복잡한 블록만 원래 순서로 이미지화합니다. 원시 HTML은 텍스트로 취급합니다.

표와 코드

채팅에는 표 이미지, 이메일에는 편집 가능한 HTML 표를 제공합니다. 코드는 구문 강조와 줄바꿈을 하며 여러 이미지로 나눌 수 있습니다. 알 수 없는 언어도 원문 배치를 유지하고 인라인 코드는 텍스트로 남습니다.

수식과 도표

LaTeX 원본과 mermaid 코드 펜스를 유지하세요. 로컬에서 PNG로 렌더링합니다. 표 셀 안의 수식은 현재 원본을 남깁니다. 외부 TeX 확장, 사용자 Mermaid 설정, 외부 도표 리소스는 지원하지 않습니다.

최소 예제로 확인

아래 예제를 초안에 붙여 넣고 텍스트·표 이미지·텍스트 순서를 확인하세요. 일반 단어를 수정해 텍스트인지 확인합니다. 미리보기만으로 대상 앱 검증이 되지는 않습니다.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
