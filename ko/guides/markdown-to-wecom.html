Markdown 텍스트와 이미지를 WeCom에 순서대로 공유

텍스트와 PNG를 구간별로 복사하는 방법과 Mac 초안 검증 범위를 설명합니다.

내용 확인일：2026-10-18

바로 답하기여러 번 붙여넣는 이유웹과 데스크톱검증 범위사용 순서재현 가능한 공개 예제구현 및 검증 기록

바로 답하기

Markdown을 붙여 넣고 WeCom을 선택합니다. 이미지가 있으면 구간 패널이 열립니다. 각 텍스트 또는 PNG를 복사한 즉시 같은 초안에 붙여 넣은 다음 다음 구간으로 진행하세요.

여러 번 붙여넣는 이유

검증한 Mac에서는 HTML과 텍스트를 함께 주면 텍스트만 남고 PNG·HTML·텍스트를 함께 주면 PNG만 남았습니다. 분리 복사로 전체 순서를 유지하며 한 번 붙여넣기를 보장하지 않습니다.

웹과 데스크톱

모두 구간 복사를 지원합니다. 웹은 브라우저 클립보드 권한이 필요하고 데스크톱 트레이 변환은 별도 패널을 엽니다. 패널은 복사를 기록할 뿐 실제 붙여넣기를 감지하지 못하고 메시지도 보내지 않습니다.

검증 범위

Mac WeCom 5.0.12 (70798)의 초안에서 웹 5개 구간·이미지 2장, 데스크톱 3개 구간·이미지 1장을 확인했습니다. 전송하지 않았으며 Windows, 전송 후 결과, 강조 서식 유지는 미검증입니다.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
