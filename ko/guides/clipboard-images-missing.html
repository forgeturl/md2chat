Markdown을 채팅에 붙여 넣으면 이미지가 사라질 때

원본·미리보기·복사 옵션·채팅 입력을 나눠 이미지 누락 원인을 확인합니다.

내용 확인일：2026-10-18

바로 답하기미리보기에 이미지가 없을 때미리보기만 정상일 때유용한 진단 정보실제 결과를 구분하기사용 순서재현 가능한 공개 예제구현 및 검증 기록

바로 답하기

먼저 md2chat 미리보기에서 이미지를 확인하세요. 없으면 원본을 고칩니다. 미리보기에는 있는데 채팅에서 사라지면 DingTalk·Feishu의 데스크톱 사용, Feishu 입력창 확장, WeCom 순차 복사를 확인하세요.

미리보기에 이미지가 없을 때

Markdown URL, 원본 접근 가능 여부, 복사 데이터에 실제 이미지가 포함됐는지 확인합니다. 원격 호스트가 차단하거나 웹에서 로컬 경로를 읽지 못할 수 있습니다. 자리 표시자로는 원본 이미지를 복원할 수 없습니다.

미리보기만 정상일 때

대상 앱은 HTML, 파일 참조, PNG 중 가져올 형식을 선택합니다. 공개 예제와 대상 가이드로 최소 재현을 해 보세요. 이메일 편집기와 수신자는 내장 data URI 이미지를 제거할 수도 있습니다.

유용한 진단 정보

OS·브라우저 또는 데스크톱·md2chat·대상 버전과 처음 실패한 단계를 기록하세요. 가상 내용으로 진단하며 보고서는 클립보드를 덮어쓰므로 마지막에 복사합니다. Windows DingTalk 이미지는 img 태그 대신 JSON 속성 안에 있을 수 있습니다.

실제 결과를 구분하기

미리보기, 복사, 초안 붙여넣기, 전송 결과를 따로 검증하세요. 처음과 끝 문장, 이미지 개수, 텍스트 편집 여부를 확인하고 업무 메시지·원본 이미지 URL·인증 정보는 보고하지 마세요.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
