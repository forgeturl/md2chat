Markdown 표와 이미지를 DingTalk에 붙여 넣기

데스크톱 사용법과 Mac·Windows의 서로 다른 검증 범위를 설명합니다.

내용 확인일：2026-10-18

바로 답하기표가 이미지가 되는 이유Mac과 Windows이미지 누락 진단사용 순서재현 가능한 공개 예제구현 및 검증 기록

바로 답하기

데스크톱에 Markdown을 붙여 넣고 미리보기 후 DingTalk 복사를 선택합니다. 자신의 초안에서 처음 텍스트·표 이미지·마지막 텍스트를 확인하세요. 웹 편집기의 DingTalk 복사는 비활성화되어 있습니다.

표가 이미지가 되는 이유

채팅 입력창은 Markdown 렌더러가 아닙니다. 막대로 구분한 표를 그대로 표시하지 않을 수 있어 md2chat은 표를 PNG로 만들고 주변 문장은 텍스트로 남깁니다.

Mac과 Windows

Apple Silicon Mac에서 네이티브 텍스트·이미지·텍스트 붙여넣기를 검증했습니다. Windows는 PNG를 포함한 노드 트리와 HTML·일반 텍스트 대체 형식을 만듭니다. 원본 샘플을 HTML로 다시 작성해 이미지 2장이 유지된 확인은 있지만 새 생성 결과는 현재 클라이언트에서 검증해야 합니다.

이미지 누락 진단

OS, md2chat, DingTalk 버전을 기록하고 가상의 예제로 진단하세요. Windows 이미지는 JSON 속성 안에 있을 수 있으므로 일반 img 태그 개수만으로 판단할 수 없습니다.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
