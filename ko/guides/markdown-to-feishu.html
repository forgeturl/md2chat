Markdown 텍스트와 이미지를 Feishu에 붙여 넣기

펼친 서식 입력창 사용법과 Mac 검증 기록, Windows의 검증 한계를 설명합니다.

내용 확인일：2026-10-18

바로 답하기입력창을 펼치는 이유Mac 검증과 Windows 한계초안 확인사용 순서재현 가능한 공개 예제구현 및 검증 기록

바로 답하기

데스크톱에서 Markdown을 변환하고 Feishu 복사를 선택하세요. 붙여넣기 전에 Feishu 서식 입력창을 펼칩니다. 일반 텍스트는 편집 가능하며 복잡한 블록은 이미지입니다. 웹에서는 Feishu 복사를 제공하지 않습니다.

입력창을 펼치는 이유

일반 입력창과 펼친 편집기는 서로 다른 클립보드 가져오기 경로를 사용할 수 있습니다. 검증한 Mac 경로는 네이티브 편집기 조각을 제공합니다. HTML의 이미지 참조만으로 가져오기 성공을 증명할 수 없습니다.

Mac 검증과 Windows 한계

Mac은 이미지 2장, 주변 문장, 굵게·기울임·취소선과 전송 결과를 확인했습니다. Windows는 Feishu 7.51.0.45 샘플을 바탕으로 네이티브 조각과 로컬 PNG 참조를 생성하지만 새 빌드는 대상 붙여넣기 검증이 필요합니다.

초안 확인

처음 문장·표 이미지·마지막 문장을 확인하고 일반 단어를 수정해 보세요. 이미지가 없으면 펼친 입력창인지 확인한 뒤 OS와 각 앱 버전을 기록해 신고하세요.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
