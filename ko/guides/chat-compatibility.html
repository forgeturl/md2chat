DingTalk·WeChat·Feishu·WeCom·이메일 호환성

구현 형식, 초안 붙여넣기, 전송 결과를 구분하여 대상별 방법을 비교합니다.

내용 확인일：2026-10-18

대상별 형식검증한 내용아직 확인이 필요한 부분개인정보와 편집사용 순서재현 가능한 공개 예제구현 및 검증 기록

대상별 형식

Mac DingTalk는 네이티브 서식, Windows는 PNG 내장 노드 트리를 사용합니다. 데스크톱 Feishu는 편집기 조각을 쓰므로 입력창을 펼쳐야 합니다. WeChat은 HTML, 이미지 포함 WeCom은 순차 복사, 이메일은 편집 가능한 HTML 표를 사용합니다.

검증한 내용

Apple Silicon Mac DingTalk의 텍스트·이미지·텍스트를 검증했습니다. Mac WeCom 5.0.12 (70798) 초안에서는 웹 5개 구간·이미지 2장과 데스크톱 3개 구간·이미지 1장을 확인했으며 전송하지 않았습니다. Mac Feishu는 이미지 2장 혼합 및 전송 후 사용자 확인이 있습니다.

아직 확인이 필요한 부분

새 Windows DingTalk·Feishu 생성 결과는 대상 클라이언트 검증이 필요합니다. Feishu 구현은 7.51.0.45 편집기 샘플을 참고합니다. Windows WeCom과 수신 이메일 이미지는 미검증입니다. 빌드와 시스템 클립보드 왕복 성공은 대상 앱의 수용을 증명하지 않습니다.

개인정보와 편집

계정 없이 로컬로 변환합니다. 원격 이미지 요청과 로컬 PNG 캐시가 발생할 수 있습니다. 일반 텍스트는 편집 가능하지만 PNG 안의 문자는 그렇지 않습니다. WeCom 강조 서식은 보장하지 않으며 복사는 메시지를 전송하지 않습니다.

사용 순서

  1. 원본 Markdown을 복사하여 md2chat에 붙여 넣습니다.
  2. 미리보기에서 본문, 표 이미지, 마지막 문단을 확인합니다.
  3. 대상에 맞게 복사한 후 자신의 초안에서 순서와 텍스트 편집 여부를 확인합니다.
