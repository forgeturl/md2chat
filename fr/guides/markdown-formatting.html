Réponse directe

Titres, emphase, listes, tâches, liens, tableaux, images, code, LaTeX et Mermaid sont pris en charge. Le texte courant reste modifiable et les blocs complexes deviennent des images dans l’ordre. Le HTML brut est traité comme du texte.

Tableaux et code

Les chats reçoivent des images de tableaux ; l’e-mail conserve des tableaux HTML modifiables. Le code est coloré, revient à la ligne et peut former plusieurs images. Les langages inconnus gardent leur disposition ; le code en ligne reste du texte.

Formules et diagrammes

Conservez LaTeX et les blocs mermaid pour le rendu local PNG. Les formules dans les cellules gardent actuellement leur source. Les extensions TeX externes, configurations Mermaid personnalisées et ressources externes de diagrammes ne sont pas prises en charge.

Tester un cas minimal

Contrôlez texte/tableau/texte dans un brouillon et modifiez un mot courant pour confirmer qu’il reste du texte. L’aperçu ne remplace pas le test dans l’application cible.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
