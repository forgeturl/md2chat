Convertir Markdown pour WeChat avec du texte modifiable

Réponse directe

Collez le Markdown, vérifiez l’aperçu puis copiez pour WeChat. Le HTML standard et le texte suivent l’ordre original, sans capture de tout le message.

Ce qui devient une image

Tableaux, code, formules et Mermaid deviennent des images. Paragraphes et listes restent du texte. Pour corriger les mots d’un PNG, modifiez la source puis recopiez.

Toutes les versions sont-elles compatibles ?

Aucune compatibilité universelle n’est promise. Des retours positifs existent sur le HTML standard, mais système, navigateur et client influencent l’importation. Vérifiez images et dernier paragraphe avant l’envoi.

Si l’image source est illisible

Vérifiez son accès et sa présence dans l’aperçu. Le serveur distant peut limiter l’accès. Le Web ne lit pas de chemins locaux arbitraires ; le bureau traite les images locales qui passent les contrôles.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
