Réponse directe

Copiez le Markdown original de l’outil IA, collez-le dans md2chat, vérifiez l’aperçu et copiez pour la destination. Le texte reste modifiable ; tableaux, code, formules et Mermaid deviennent des images.

Pourquoi la mise en forme change

L’interface IA affiche du Markdown mais la copie peut fournir un autre format. Le chat choisit aussi ce qu’il importe. Un bon aperçu ne garantit pas la conservation de toutes les images.

Quelle source conserver

Gardez les tableaux Markdown, la source LaTeX et les blocs mermaid. Un emplacement réservé ou la description d’une formule manquante ne permet pas de la reconstruire. Les noms IA sont des exemples de sources, pas des intégrations ; aucun compte à connecter.

Choisir la bonne méthode

DingTalk et Feishu nécessitent le bureau ; déployez la saisie Feishu. WeCom avec images utilise des copies successives de texte et PNG. WeChat utilise le HTML standard ; l’e-mail reste expérimental.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
