Réponse directe

Collez le Markdown sur bureau, vérifiez puis choisissez la copie DingTalk. Contrôlez début, image du tableau et fin dans votre brouillon. Cette copie est désactivée sur le Web.

Pourquoi convertir le tableau en PNG

La saisie du chat n’est pas un moteur Markdown. Un tableau avec des barres peut perdre sa disposition. md2chat produit un PNG et conserve le texte environnant modifiable.

Mac et Windows

Le collage natif texte/image/texte a été testé sur Mac Apple Silicon. Windows génère un arbre de nœuds avec PNG intégrés et replis HTML/texte. Une source réécrite en HTML a conservé deux images, mais le contenu nouvellement généré doit encore être validé dans le client actuel.

En cas d’images manquantes

Notez les versions du système, de md2chat et de DingTalk, puis utilisez un contenu fictif pour le diagnostic. Les images Windows peuvent se trouver dans un attribut JSON plutôt que dans des balises img ordinaires.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
