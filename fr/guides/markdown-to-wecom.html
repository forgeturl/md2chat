Partager texte et images Markdown dans WeCom par segments

Copiez texte et PNG dans l’ordre, avec tests de brouillons Mac et limites explicites.

Réponse directe

Collez le Markdown et choisissez WeCom. Avec des images, un panneau de segments s’ouvre. Copiez chaque texte ou PNG et collez-le immédiatement dans le même brouillon avant de continuer.

Pourquoi plusieurs collages

Sur le Mac testé, HTML avec texte ne conservait que le texte ; PNG avec HTML et texte ne conservait que le PNG. Des copies séparées préservent l’ordre. Un collage mixte unique n’est pas garanti.

Web et bureau

Les deux proposent les segments. Le Web exige l’autorisation du presse-papiers ; la conversion depuis la zone de notification ouvre son propre panneau. Le panneau enregistre les copies, ne détecte pas les collages et n’envoie jamais de messages.

Périmètre des tests

Sur WeCom Mac 5.0.12 (70798), cinq segments Web avec deux images et trois segments bureau avec une image ont été vérifiés dans des brouillons. Aucun envoi. Windows, résultat envoyé et conservation de l’emphase restent non validés.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
