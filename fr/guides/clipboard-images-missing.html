Que faire si des images disparaissent au collage dans un chat ?

Isolez source, aperçu, copie et saisie du chat pour trouver la cause des images manquantes.

Réponse directe

Vérifiez d’abord l’image dans md2chat. Absente de l’aperçu : corrigez la source. Absente seulement du chat : utilisez le bureau pour DingTalk/Feishu, déployez Feishu ou utilisez les segments WeCom.

Image absente de l’aperçu

Contrôlez URL, accès à l’origine et présence de vraies données image dans la copie. Le serveur peut restreindre l’accès et le Web ne lit pas de chemins locaux arbitraires. Un emplacement réservé ne recrée pas une image.

Aperçu correct, collage incorrect

Le client choisit HTML, référence de fichier ou PNG. Essayez le cas minimal et la méthode cible. Les éditeurs d’e-mail et les destinataires peuvent aussi retirer les images intégrées sous forme de data URI.

Recueillir des preuves utiles

Notez système, navigateur ou bureau, versions et première étape défaillante. Utilisez du contenu fictif. Copiez le rapport en dernier car il remplace le presse-papiers. Les images DingTalk Windows peuvent être dans du JSON plutôt que dans img.

Vérifier le résultat réel

Distinguez aperçu, copie, collage dans un brouillon et envoi. Contrôlez images, début/fin et texte modifiable. Ne communiquez pas de messages privés, URL d’images originales ou identifiants dans le rapport.

Étapes

  1. Copiez le Markdown original et collez-le dans md2chat.
  2. Vérifiez le texte, l’image du tableau et le dernier paragraphe dans l’aperçu.
  3. Copiez avec l’option de destination et vérifiez l’ordre et le texte modifiable dans votre propre brouillon.
