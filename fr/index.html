Gratuit et libre · Sans compte · Traitement local

md2chat est un convertisseur Markdown gratuit et libre pour les chats. Collez une réponse IA ou du Markdown : le texte courant reste modifiable, tandis que les tableaux, le code, les formules et les diagrammes Mermaid deviennent des PNG dans leur ordre initial. Copiez ensuite pour votre application de chat.

Notes de version

Ce qui reste du texte et ce qui devient une image

Texte courant modifiable

Les paragraphes, listes et tâches restent du texte. Tableaux, blocs de code, formules et diagrammes deviennent des PNG ; modifiez la source pour changer le texte dans une image.

Copie adaptée à la destination

DingTalk et Feishu nécessitent la version de bureau. Déployez la saisie enrichie de Feishu. WeCom avec images utilise des segments ; WeChat utilise le HTML standard.

Sans compte, traitement local

Le texte et les images ne sont pas envoyés à md2chat. Les images distantes contactent leur serveur et la copie native peut conserver des PNG dans un cache local.

Questions avant de copier

Quelle différence avec une capture complète ?

Seuls les blocs complexes deviennent des images. Le texte courant peut encore être modifié, copié et recherché dans le chat.

Quels outils IA puis-je utiliser ?

Vous pouvez saisir du Markdown de ChatGPT, Claude, DeepSeek, Codex ou Cursor. Ce sont des exemples de sources, pas des intégrations officielles. Aucun compte IA à connecter.

Puis-je tout coller en une fois partout ?

Les clients importent des formats différents. Des tests de contenu mixte existent pour DingTalk Mac et la saisie déployée de Feishu Mac. WeCom avec images utilise des segments. Vérifiez avant d’envoyer.
