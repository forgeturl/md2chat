DingTalk・WeChat・Feishu・WeCom・メールの互換性

実装済みの形式、下書きの実測、送信後の確認を区別して、送信先の手順を比較します。

内容の確認日：2026-10-18

送信先別の方式確認できていること未検証の範囲プライバシーと編集操作手順再現できる公開サンプル実装と検証の記録

送信先別の方式

Mac DingTalk はネイティブのリッチテキスト、Windows は PNG 埋め込みのノードツリーを使います。Feishu はデスクトップ版のエディター断片で、展開した入力が必要です。WeChat は HTML、画像入り WeCom は分割コピー、メールは編集可能な HTML 表です。

確認できていること

Apple Silicon の Mac DingTalk で文章・画像・文章を実測しました。Mac WeCom 5.0.12 (70798) では Web の 5 区間・画像 2 枚と、デスクトップの 3 区間・画像 1 枚を下書きで検証し、送信はしていません。Mac Feishu は画像 2 枚の混在と送信後のユーザー確認があります。

未検証の範囲

新しい Windows DingTalk・Feishu の生成結果は対象クライアントでの確認が必要です。Feishu は 7.51.0.45 の原サンプルを参考にしています。Windows WeCom とメール受信側の画像は未検証です。ビルドやシステムクリップボードの成功は送信先での成功を意味しません。

プライバシーと編集

アカウント不要のローカル変換ですが、外部画像の取得と PNG のローカルキャッシュは発生する場合があります。通常の文章は編集可能、画像内の文字は編集不可です。WeCom の強調装飾は保証せず、コピー操作はメッセージを送信しません。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
