AI の回答や Markdown をチャットに共有するには

ChatGPT、Claude、DeepSeek、Codex、Cursor の Markdown を、文章が編集可能なチャット用コンテンツに変換する手順です。

内容の確認日：2026-10-18

結論コピー後に見た目が変わる理由必要な原文送信先を選ぶ操作手順再現できる公開サンプル実装と検証の記録

結論

AI ツールから Markdown の原文をコピーして md2chat に貼り付け、プレビューを確認して送信先に合わせてコピーします。文章は編集可能なまま、表・コード・数式・Mermaid 図は画像になります。

コピー後に見た目が変わる理由

AI 画面の表示とコピーボタンが渡す形式は同じとは限りません。チャット側も取り込む形式を選ぶため、プレビューが正しくても画像がすべて残るとは限りません。

必要な原文

表の Markdown、LaTeX の数式、mermaid のコードフェンスを残してください。画像や数式の代わりに説明文しかなければ復元できません。AI ツール名は入力元の例で、公式連携ではなく、アカウント接続も不要です。

送信先を選ぶ

DingTalk と Feishu はデスクトップ版が必要です。Feishu の入力は展開し、WeCom の画像は文章と PNG を順番にコピーします。WeChat は標準 HTML、メールは実験的対応です。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
