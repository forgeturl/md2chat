結論

デスクトップ版に Markdown を貼り付け、プレビューを確認して DingTalk 用コピーを選びます。自分の下書きで冒頭・表の画像・末尾を確認してください。Web 版の DingTalk コピーは無効です。

表は PNG、周囲の文章は編集可能

チャット入力は Markdown の表を表示するとは限りません。md2chat は表を PNG に変換し、周囲の文章は文字として残します。

Mac と Windows の違い

Apple Silicon の Mac では文章・画像・文章のネイティブ貼り付けを検証済みです。Windows は PNG を埋め込んだノードツリーと HTML・プレーンテキストの代替形式を生成します。原サンプルを HTML に書き直して画像 2 枚が残った報告はありますが、新しい生成結果は現行クライアントでの確認が必要です。

画像が消える場合

OS、md2chat、DingTalk のバージョンを記録し、架空の内容で診断してください。Windows の画像は JSON 属性内にある場合があり、通常の img タグ数だけでは数えられません。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
