Markdown をチャットに貼り付けると画像が消える場合

原文、プレビュー、コピー方法、チャット入力を分けて原因を確認します。

内容の確認日：2026-10-18

結論プレビューに画像がないプレビューにはあるが貼り付けで消える役立つ診断情報実際の結果を区別する操作手順再現できる公開サンプル実装と検証の記録

結論

まず md2chat のプレビューに画像があるか確認します。なければ原文を直します。表示されるのにチャットで消える場合は、DingTalk・Feishu のデスクトップ版、Feishu の入力展開、WeCom の分割方式を確認してください。

プレビューに画像がない

Markdown の URL、配信元へのアクセス、コピー元に画像データが含まれるかを確認します。外部ホストの制限や Web 版で読めないローカルパスの場合があります。代わりの説明文だけでは画像を復元できません。

プレビューにはあるが貼り付けで消える

チャットは HTML・ファイル参照・PNG のどれを使うか選びます。公開サンプルと対象ガイドで最小構成を試してください。メールのエディターや受信側は埋め込み data URI 画像を除去する場合もあります。

役立つ診断情報

OS、ブラウザーまたはデスクトップ、md2chat、送信先のバージョンと最初に失敗した段階を記録します。架空の内容を使い、クリップボードを置き換える診断レポートは最後にコピーします。Windows DingTalk の画像が JSON 属性内にある点にも注意します。

実際の結果を区別する

プレビュー・コピー・下書きへの貼り付け・送信後の結果は別々に確認します。画像数、前後の文章、編集可能性を確認し、業務メッセージ・原画像 URL・認証情報は報告に含めないでください。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
