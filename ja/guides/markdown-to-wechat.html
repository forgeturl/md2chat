Markdown を WeChat の文章と画像に変換する

文章を編集可能なまま、表・コード・数式を画像にして、WeChat の下書きで確認する方法です。

内容の確認日：2026-10-18

結論

Markdown を貼り付けてプレビューを確認し、WeChat 用にコピーします。全体を一枚の画像にせず、元の順番で標準 HTML とプレーンテキストを書き込みます。

画像になるもの

表・コードブロック・数式・Mermaid 図は画像になり、通常の段落やリストは文章のままです。画像内の文字を直すには原文を変更してコピーし直します。

すべてのバージョンで動きますか？

全バージョン対応は保証しません。標準 HTML の貼り付け成功例はありますが、OS・ブラウザー・クライアントのバージョンによって結果が変わります。送信前に画像数と最後の段落を確認してください。

原画像を読み込めない場合

原画像がアクセス可能で、プレビューに表示されるか確認します。外部ホストの制限もあります。Web 版は任意のローカルパスを読み込めず、デスクトップ版は検証を通ったローカル画像を扱います。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
