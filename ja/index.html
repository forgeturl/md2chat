md2chat は無料・オープンソースの Markdown チャット変換ツールです。AI の回答や Markdown を貼り付けると、通常の文章は編集可能なまま、表・コード・数式・Mermaid 図を元の順番で PNG に変換し、送信先に合わせてコピーできます。

リリースノート

文章として残る部分と、画像になる部分

通常の文章は編集可能

段落・リスト・タスクは文章として残ります。表・コードブロック・数式・図は PNG になり、画像内の文字を直すには元の Markdown を編集します。

送信先に合ったコピー方法

DingTalk と Feishu はデスクトップ版を使い、Feishu ではリッチテキスト入力を展開します。画像を含む WeCom は順番に分割コピー、WeChat は標準 HTML を使います。

アカウント不要、ローカル処理

本文や画像を md2chat にアップロードしません。ただし外部画像は配信元へアクセスし、デスクトップのネイティブコピーでは PNG をローカルにキャッシュする場合があります。

送信先ごとの手順と検証範囲

送信先推奨手順検証の範囲
DingTalkデスクトップ版でコピーし、自分の下書きに貼り付けます。Apple Silicon の Mac で文章と画像の混在を検証済み。Windows の新しい生成処理は現行クライアントでの確認が必要です。
Feishuデスクトップ版でコピーし、リッチテキスト入力を展開します。Mac では画像 2 枚を含む送信結果を確認済み。Windows は新ビルドでの受け入れ確認が必要です。
WeComパネルの順に文章と PNG をコピーして貼り付けます。Mac 5.0.12 の下書きで検証。Windows と送信後の表示は未検証です。
WeChat / メールWeChat は標準 HTML、メールは編集可能な HTML 表を使います。WeChat は使用中のクライアントで確認が必要です。メール受信側の画像表示は未検証です。

互換性と検証記録を確認

使う前によくある質問

全体のスクリーンショットとは何が違いますか？

通常の文章を残し、複雑な部分だけを画像にします。チャット側でも通常の文章を編集・コピー・検索できます。

どの AI ツールで使えますか？

ChatGPT、Claude、DeepSeek、Codex、Cursor などの Markdown を入力できます。これらは入力元の例であり、公式連携ではありません。AI アカウントの接続は不要です。

どのチャットにも一度で貼り付けられますか？

クライアントによって取り込み方式が異なります。Mac の DingTalk と展開した Feishu 入力では混在データの実測があります。画像を含む WeCom は分割コピーを使い、送信前に結果を確認してください。
