Cómo pegar texto e imágenes Markdown en Feishu

Usa escritorio y el editor ampliado de Feishu, con pruebas de Mac y límites explícitos de Windows.

Respuesta directa

En escritorio, pega Markdown y copia para Feishu. Amplía el editor con formato antes de pegar. El texto normal sigue editable y los bloques complejos pasan a imágenes. La web no ofrece esta copia.

Por qué ampliar el editor

La entrada normal y el editor ampliado pueden importar formatos por vías diferentes. La prueba Mac proporciona un fragmento nativo. Una referencia a imagen en HTML no demuestra que Feishu la importe.

Pruebas de Mac y límites de Windows

En Mac se confirmaron dos imágenes, texto, negrita, cursiva, tachado y el resultado enviado. Windows genera fragmentos nativos y referencias PNG locales a partir de una muestra Feishu 7.51.0.45. La nueva compilación aún requiere una prueba de pegado.

Revisa tu borrador

Comprueba inicio, tabla, final y la edición de una palabra normal. Si falta una imagen, revisa que el editor esté ampliado y anota las versiones de SO y aplicaciones.

Pasos

  1. Copia el Markdown original y pégalo en md2chat.
  2. Revisa el texto, la imagen de la tabla y el último párrafo en la vista previa.
  3. Copia con la opción de tu destino y comprueba el orden y el texto editable en tu propio borrador.
