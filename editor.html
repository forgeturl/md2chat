使用说明

让 Markdown 更适合聊天。

从 Markdown 到聊天，只需三步

  1. 1

    粘贴 Markdown

    在左侧粘贴文字或图片，右侧会自动生成预览。

  2. 2

    选择目标平台

    点击预览下方的平台按钮，将转换结果复制到剪贴板。

  3. 3

    到聊天窗口粘贴

    切换到聊天窗口，按 ⌘V / Ctrl+V 粘贴。

图片

将完整内容合成一张 PNG，图片中的文字不可编辑。

代码、公式和图表会自动转为图片，并保留原文顺序。

按目标平台选择复制方式

钉钉、飞书复制仅限桌面版；网页版可使用微信、企微和邮件。

微信
复制后直接粘贴；若聊天窗口丢图，可改用「图片」。
钉钉
Mac 支持一次粘贴图文；Windows 请核对图片和文字顺序。
飞书
请先展开飞书富文本输入框，再一次粘贴图文。
企微
含图片时按弹窗顺序逐段复制、粘贴。
邮件
保留可编辑表格；发送前请确认粘贴结果。

Windows 飞书、邮件为实验性适配，请核对粘贴结果。

支持的格式

文字排版
标题、粗体、斜体、删除线、列表、任务项、引用和链接。
表格
表格默认转为图片；邮件模式保留可编辑表格。
代码、公式与图表
代码、公式和图表会自动转为图片，并保留原文顺序。

原始 HTML 按文字显示；表格单元格内的公式暂保留源码。

隐私与数据

纯前端处理 · 无需登录 · 不上传正文或图片 · 不持久化保存输入

  • 输入内容只在当前窗口中使用，关闭或刷新前请自行保存。
  • 远程图片从原网址加载；复制用图片可能临时缓存在本机。
  • 复制后的内容由系统剪贴板和目标应用管理。
开源实验版反馈兼容性问题 ↗

剪贴板排查

仅在点击或粘贴时读取浏览器开放的格式，报告包含图片引用类型和脱敏结构。请分别读取转换器与钉钉复制的内容，再复制报告；截图或复制其他内容会替换当前剪贴板。报告不含正文、链接或文件路径，不上传内容。

Windows 钉钉粘贴测试（会替换剪贴板）：先测试无图片 HTML。再从钉钉复制一条图文，确认能直接粘回草稿后，点击“重写当前 HTML”并再次粘贴。只记录两次是否出现内容，无需发送。测试不上传或保存 HTML。
