使用说明

纯前端处理 · 无需登录 · 不上传正文或图片 · 不持久化保存输入

点击可用的平台图标复制，再到对应聊天框粘贴。企微图文请按分段窗口的顺序逐段复制粘贴。Mac 飞书请先展开富文本输入框再一次粘贴。网页和 Windows 飞书、邮件为实验性适配，请确认粘贴结果。

支持的格式与兼容性

支持标题、粗体、斜体、删除线、编号和嵌套列表、任务项、引用、链接、代码块、分隔线、表格及图片。原始 HTML 按文字显示，支持 $…$ / \(…\) 行内公式、$$…$$ / \[…\] 独立公式和 mermaid 代码块。代码块使用 GitHub 浅色语法高亮，长行折行、长代码分图，未知语言按原文排版。代码、公式与图表转为 PNG，纯文本保留源码；表格单元格内的公式暂保留源码。

桌面版在 macOS 上使用钉钉原生图文格式；Mac 飞书支持一次图文粘贴，请先展开飞书富文本输入框；Windows 钉钉一次图文粘贴尚未解决，保留纯文本兜底，提供可选分段复制与 HTML 排查测试。分段后文字保持可编辑，Windows 图片粘贴仍需实测。网页提供微信、飞书、邮件标准图文复制，邮件模式保留可编辑表格；企微含图片时使用分段复制，按顺序逐段粘贴，文字可编辑但强调样式不保证保留。钉钉复制仅限桌面版。图片读取受限时会阻止复制并提示补图。网页无法访问钉钉专有剪贴板格式。桌面版不保存输入正文；复制用图片缓存在本机。Mac 启动时清理超过 7 天的旧图（剪贴板含钉钉或 Chromium 自定义格式时暂缓，避免影响原生图文）；Mac 飞书在下一次成功复制后清理旧图；Windows 在下一次成功复制钉钉内容后清理旧图，保留当前剪贴板引用。远程原图仍需向图片来源请求。

开源实验版 · 反馈兼容性问题 ↗

远程图片会从原网址加载；刷新页面会清空输入。托管平台可能记录访问日志；复制后的内容由系统剪贴板及目标应用管理。

剪贴板排查

仅在点击或粘贴时读取浏览器开放的格式，报告包含图片引用类型和脱敏结构。请分别读取转换器与钉钉复制的内容，再复制报告；截图或复制其他内容会替换当前剪贴板。报告不含正文、链接或文件路径，不上传内容。

Windows 钉钉粘贴测试（会替换剪贴板）：先测试无图片 HTML。再从钉钉复制一条图文，确认能直接粘回草稿后，点击“重写当前 HTML”并再次粘贴。只记录两次是否出现内容，无需发送。测试不上传或保存 HTML。
