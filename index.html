md2chat 免费吗？

免费，且采用 MIT 开源许可证。无需注册账号，就能使用桌面版和网页版。你也可以在 GitHub 查看代码、反馈问题或参与改进。

可以转换哪些 AI 工具的回答？

从 DeepSeek、ChatGPT、Claude、Codex、Cursor 等工具复制的 Markdown 都可以作为输入，也可以粘贴自己写的文档。无需连接 AI 账号。复制时保留 Markdown 源码，转换后在右侧预览确认即可。

我的文字和图片会上传吗？

转换在本机完成，不向 md2chat 服务器上传正文或图片。引用远程图片时，会访问图片的原网址；桌面版会在本机缓存复制所需的图片。

桌面版和网页版怎么选？

想先看看转换效果，可以直接打开网页版。经常分享内容，或需要钉钉、飞书复制、菜单栏和托盘快捷转换，可以下载桌面版。安装后即可使用，无需额外安装插件或助手。

微信、钉钉、飞书和企微怎么粘贴？

预览后选择对应平台复制，再到目标聊天框粘贴。Mac 飞书先展开富文本输入框；企业微信图文按提示分段复制、依次粘贴。不同系统和客户端的支持范围有所不同，具体用法请看平台使用指南。

能一直放在菜单栏或托盘里吗？

可以。桌面版支持 macOS 菜单栏和 Windows 系统托盘，关闭窗口后仍可随时打开，也能从菜单快速转换剪贴板内容。开机自启动可在首选项中按需开启。
