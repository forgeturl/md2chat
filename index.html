A few things to know

打开之前，
你可能想知道。

支持从 DeepSeek、Codex、Cursor 复制的内容吗？

支持将这些工具中复制到的 Markdown 作为输入，包括标题、列表、表格、代码、公式和 Mermaid。不同工具的复制按钮可能提供 Markdown、纯文本或富文本；请先预览确认。md2chat 不连接 AI 账号，也不会读取 AI 聊天记录。品牌示例不代表官方集成，目标聊天客户端的兼容性另见使用指南。

我的文字和图片会上传吗？

转换在本机完成，不要求登录，不向 md2chat 服务器上传正文或图片。远程原图仍会向其来源网站发起请求。桌面版会在本机缓存复制需要的图片，超过 7 天后启动时清理；当前剪贴板仍含钉钉图文时暂缓清理。

为什么桌面版比网页更适合钉钉？

网页只能通过浏览器开放的剪贴板格式复制。桌面版可以直接写入 macOS 钉钉使用的图文结构，保留文字、图片和排列顺序，不需要把整篇内容转成 PNG。

钉钉、微信都能用吗？

桌面版为 macOS 钉钉提供原生图文格式，同时提供标准 HTML 和纯文字。不同客户端的粘贴规则不同，实际支持范围和测试记录请查看仓库兼容性说明。发送前请确认图片完整。

需要额外安装插件或助手吗？

不需要。桌面应用包含转换界面和剪贴板写入能力。macOS 下载 DMG 后安装应用。0.5.1 及更早版本未签名，仅供测试；0.6.0 的 Mac 发布要求签名和公证，以实际 Release 为准。

支持托盘和开机自启动吗？

支持 macOS 菜单栏和 Windows 系统托盘。关闭窗口后继续驻留，在托盘菜单中打开窗口、进入首选项配置开机自启动，或退出应用。自启动默认不主动开启；未签名的 macOS 包可能需要系统批准或无法注册。

这个项目收费吗？

项目采用 MIT 开源许可证。你可以免费使用、查看代码、反馈问题，也可以参与改进。下载与更新通过 GitHub Releases 发布。
