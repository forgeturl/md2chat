How to paste Markdown text and images into Feishu

Use md2chat desktop with the expanded Feishu rich-text input, including the tested Mac workflow and Windows acceptance limits.

Content reviewed：2026-10-18

Direct answer

Use md2chat desktop, paste Markdown and choose Feishu copy. Expand the Feishu rich-text input before pasting. Ordinary text remains editable while tables, code, equations and diagrams become images. The web editor does not offer Feishu copying.

Why expand the input?

The normal chat input and expanded editor can use different clipboard-import paths. The tested Mac workflow supplies a native editor fragment. An image reference in standard HTML does not prove that Feishu will import it.

Mac evidence and Windows limits

The Mac test retained two images, surrounding text, bold, italic and strikethrough, with user confirmation after sending. Windows generates native fragments and local PNG references based on a Feishu 7.51.0.45 editor sample. A new build still needs a destination paste test.

Verify your draft

Check the beginning, table image and ending. Try editing an ordinary word. If an image is missing, confirm the expanded input and record your OS, md2chat and Feishu versions before reporting the issue.

Step by step

  1. Paste the public sample into md2chat desktop and wait for the preview.
  2. Choose Feishu copy and switch to your own chat draft.
  3. Expand the rich-text input, then press ⌘V or Ctrl+V.
  4. Check the text/image/text order before you choose to send.

A public example

# Weekend book club

Start: see you on Saturday.

| Activity | Duration |
| --- | --- |
| Quiet reading | 20 minutes |
| Discussion | 30 minutes |

End: remember to bring a book.

Check the opening text, table image and closing text in your own draft. Ordinary text should remain editable.
