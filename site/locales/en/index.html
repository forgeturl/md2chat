Release notes

Keep ordinary text. Render complex blocks as images.

Editable ordinary text

Paragraphs, lists and task items remain text. Tables, code blocks, equations and diagrams become PNGs; edit their source to change text inside an image.

Copy for your destination

DingTalk and Feishu require desktop. Expand the Feishu rich-text input first. WeCom with images uses sequential copies; WeChat uses standard HTML.

No account, local processing

Content is not uploaded to md2chat. Remote images still contact their original hosts, and desktop native copying can cache PNGs locally.

Before you copy

How is this different from a screenshot?

md2chat retains ordinary text and renders only complex blocks as images. You can edit, copy and search ordinary text in the destination instead of sending one screenshot of the entire message.

Which AI tools can I use?

Markdown from ChatGPT, Claude, DeepSeek, Codex and Cursor can be used as input. These are content-source examples, not official integrations. No AI account connection is required.

Can I paste everything in one operation?

Client import behavior differs. Native mixed-content evidence exists for Mac DingTalk and the expanded Mac Feishu input. WeCom with images uses sequential copies. Inspect the current client before sending.
