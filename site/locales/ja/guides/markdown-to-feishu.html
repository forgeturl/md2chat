Markdown の文章と画像を Feishu に貼り付ける

展開したリッチテキスト入力を使う手順と、Mac の実測・Windows の未検証範囲です。

内容の確認日：2026-10-18

結論入力を展開する理由Mac の実測と Windows の制限下書きで確認操作手順再現できる公開サンプル実装と検証の記録

結論

デスクトップ版で Markdown を変換し、Feishu 用コピーを選びます。貼り付け前に Feishu のリッチテキスト入力を展開してください。通常の文章は編集可能、複雑なブロックは画像です。Web 版では使えません。

入力を展開する理由

通常の入力と展開したエディターは取り込み経路が異なる場合があります。Mac の検証済み手順はネイティブのエディター断片を渡します。HTML に画像参照があるだけでは取り込み成功とはいえません。

Mac の実測と Windows の制限

Mac で画像 2 枚、周囲の文章、太字・斜体・取り消し線と送信後の結果を確認しています。Windows は Feishu 7.51.0.45 のサンプルからネイティブ断片とローカル PNG 参照を生成しますが、新ビルドの貼り付け確認が必要です。

下書きで確認

冒頭・表の画像・末尾を確認し、普通の単語を編集してみます。画像が消える場合は入力の展開と各アプリのバージョンを確認して報告してください。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
