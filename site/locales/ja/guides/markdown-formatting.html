編集可能な部分と PNG に変わる部分を、再現できる表の例で説明します。

内容の確認日：2026-10-18

結論表とコード数式と図最小の確認方法操作手順再現できる公開サンプル実装と検証の記録

結論

見出し・強調・リスト・タスク・リンク・表・画像・コード・LaTeX・Mermaid に対応します。通常の文章は編集可能なまま、複雑なブロックを元の順番で画像にします。生の HTML は文字として扱います。

表とコード

チャット用の表は画像、メール用の表は編集可能な HTML です。コードは色分けと折り返しを行い、複数の画像になることがあります。不明な言語も原文の配置を保ち、インラインコードは文字のままです。

数式と図

LaTeX 原文と mermaid コードフェンスを残してください。ローカルで PNG に変換します。表のセル内の数式は現状原文を残します。外部 TeX 拡張、独自 Mermaid 設定、外部図リソースは非対応です。

最小の確認方法

以下のサンプルを使い、下書きで文章・表の画像・文章の順序を確認します。普通の単語を編集できるか試してください。プレビューだけでは送信先の検証にはなりません。

操作手順

  1. 元の Markdown をコピーして md2chat に貼り付けます。
  2. プレビューで本文、表の画像、最後の段落を確認します。
  3. 送信先に合った方法でコピーし、自分の下書きで順序と編集可能な文章を確認します。
