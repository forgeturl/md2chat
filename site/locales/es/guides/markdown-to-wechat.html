Convertir Markdown a WeChat manteniendo texto editable

Respuesta directa

Pega Markdown, revisa y copia para WeChat. Se escribe HTML estándar y texto en el orden original, no una captura de todo el mensaje.

Qué se convierte en imagen

Tablas, código, fórmulas y Mermaid pasan a imágenes. Párrafos y listas siguen siendo texto. Para cambiar palabras dentro de un PNG hay que editar el original y copiar de nuevo.

¿Funciona en todas las versiones?

No se garantiza compatibilidad universal. Hay comentarios positivos sobre HTML estándar, pero influyen el SO, navegador y cliente. Antes de enviar, comprueba las imágenes y el último párrafo.

Si no se puede leer una imagen

Verifica que el original sea accesible y aparezca en la vista previa. El servidor remoto puede restringirlo. La web no lee rutas locales arbitrarias; escritorio admite imágenes locales que superan las comprobaciones.

Pasos

  1. Copia el Markdown original y pégalo en md2chat.
  2. Revisa el texto, la imagen de la tabla y el último párrafo en la vista previa.
  3. Copia con la opción de tu destino y comprueba el orden y el texto editable en tu propio borrador.
