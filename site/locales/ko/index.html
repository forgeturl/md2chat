무료 오픈 소스 · 가입 불필요 · 로컬 처리

md2chat은 무료 오픈 소스 Markdown 채팅 변환 도구입니다. AI 답변이나 Markdown을 붙여 넣으면 일반 문장은 편집 가능한 텍스트로 남고, 표·코드·수식·Mermaid 도표는 원래 순서대로 PNG가 됩니다. 대상 채팅에 맞춰 복사할 수 있습니다.

Markdown 원문

원문을 수정하면 오른쪽에 결과가 표시됩니다.

변환 후 · 바로 공유

미리보기 생성 중…

변환하지 못했습니다. 원문을 확인하고 다시 시도하세요.

  1. 01

    콘텐츠 붙여넣기

    Markdown 또는 AI 답변을 붙여넣으세요. 텍스트, 코드, 표, 수식, 다이어그램을 지원합니다.

  2. 02

    미리보기 확인

    텍스트는 편집 가능한 상태로, 복잡한 콘텐츠는 선명한 이미지로 원문 순서를 유지합니다.

  3. 03

    복사하여 공유

    복사 형식을 선택하고 안내에 따라 채팅에 붙여넣으세요.

일반 텍스트는 편집 가능

문단·목록·작업 항목은 텍스트로 남습니다. 표·코드 블록·수식·도표는 PNG가 되며, 이미지 속 글자를 고치려면 원본을 수정해야 합니다.

대상에 맞는 복사 방법

DingTalk와 Feishu는 데스크톱 앱을 사용하고 Feishu의 서식 입력창을 펼치세요. 이미지가 있는 WeCom은 순차 복사, WeChat은 표준 HTML을 사용합니다.

계정 없이 로컬 처리

본문이나 이미지를 md2chat에 업로드하지 않습니다. 다만 원격 이미지는 원본 호스트에 요청하며 네이티브 복사 과정에서 PNG를 로컬에 캐시할 수 있습니다.

채팅별 작업 순서와 검증 범위

대상권장 방법현재 검증 범위
DingTalk데스크톱에서 복사한 뒤 자신의 초안에 붙여 넣습니다.Apple Silicon Mac의 네이티브 혼합 붙여넣기는 검증했습니다. Windows 새 생성 경로는 현재 클라이언트에서 확인이 필요합니다.
Feishu데스크톱에서 복사하고 서식 입력창을 펼칩니다.Mac에서는 이미지 2장과 전송 결과를 확인했습니다. Windows는 새 빌드의 클라이언트 검증이 필요합니다.
WeCom패널 순서대로 텍스트와 PNG를 각각 복사해 붙여 넣습니다.Mac 5.0.12 초안에서 검증했습니다. Windows 및 전송 후 결과는 미검증입니다.
WeChat / 이메일WeChat은 표준 HTML, 이메일은 편집 가능한 HTML 표를 사용합니다.사용 중인 WeChat에서 확인해야 합니다. 수신된 이메일의 이미지 표시도 미검증입니다.

호환성 및 검증 기록 확인

사용 전 자주 묻는 질문

전체 화면 캡처와 무엇이 다른가요?

일반 문장은 남기고 복잡한 블록만 이미지로 바꿉니다. 채팅에서도 일반 텍스트를 편집·복사·검색할 수 있습니다.

어떤 AI 도구와 사용할 수 있나요?

ChatGPT, Claude, DeepSeek, Codex, Cursor 등의 Markdown을 입력할 수 있습니다. 입력 출처의 예시이며 공식 연동이 아닙니다. AI 계정 연결도 필요 없습니다.

모든 채팅에 한 번에 붙여 넣을 수 있나요?

클라이언트별 가져오기 방식이 다릅니다. Mac DingTalk와 펼친 Mac Feishu 입력창은 혼합 콘텐츠 검증이 있습니다. 이미지가 있는 WeCom은 순차 복사를 사용하고 전송 전에 결과를 확인하세요.
