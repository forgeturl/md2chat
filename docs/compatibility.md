# 兼容性与证据范围

## 纯前端版本

| 能力 | 范围 |
| --- | --- |
| 解析、预览、表格转 PNG | 在浏览器内完成 |
| 本地图片 | 通过用户粘贴获得，浏览器内解码 |
| 远程图片 | 默认自动加载，依赖图片来源的 CORS 与访问权限 |
| 复制 | 标准 `text/html` 与 `text/plain`，浏览器需允许剪贴板写入 |
| 聊天框图文混排 | 待不同系统、浏览器和客户端版本分别验证 |
| 排查 | 仅浏览器可见格式，不检查原生专有数据 |

建议在 HTTPS 或 localhost 页面使用。直接双击 file URL 可能遇到权限差异。无 Async Clipboard API 时，尝试浏览器原生 copy 事件；失败会明确提示，不会把静默丢图当成成功。

## 已知问题

- 一次 macOS 钉钉来源样本的浏览器粘贴事件提供了 `text/plain` 和 `text/html`；HTML 含远程图片引用，但没有独立图片数据，浏览器读取失败。没有据此确定是跨域、权限还是网络问题，也没有泛化到所有钉钉版本。样本正文、地址和截图未纳入仓库。
- 桌面版使用 macOS 原生剪贴板，网页仍使用浏览器 API；二者兼容性证据分别记录。
- 图片在网页中可见，不代表可以读取像素、写入剪贴板或被目标应用保留。每一环都需要独立验证。
- 公式与 Mermaid 转为 PNG；已在内置浏览器检查行内公式、分式、中文流程图与时序图的渲染。目标聊天框是否保留这些图片仍须实测。
- 表格单元格内公式暂保留源码；不支持 TeX 外部扩展、Mermaid 自定义配置和外部资源，含 HTML 标签的图形可能无法导出。
- 代码块转为带颜色和行号的 PNG，行内代码保留文字；代码图片不能在目标聊天框直接编辑，标准纯文本副本仍含完整源码。目标聊天框是否保留图片需实测。
- 本工具不提供自动消息发送，也不会调用聊天工具机器人 API。

报告问题时，请使用虚构的“文字 + 两张图片 + 表格”内容，分别记录来源、网页结果和目标粘贴结果。可以使用页面底部的元数据排查报告，避免提供完整工作消息。

## 2026-10-16 macOS Chrome → 钉钉输入框实测

使用虚构的“前文 + 苹果/茶杯表格 + 后文”样本，没有发送消息。

| 复制方式 | 当前客户端的实际粘贴结果 |
| --- | --- |
| 标准 HTML + text/plain | 采用纯文本副本，表格图片未显示 |
| 仅 HTML | 输入框没有插入内容 |
| Chrome 原生选区复制 | 前后文字保留，图片位置为空 |
| HTML + text/plain + image/png | 只插入 PNG，前后文字丢失 |
| 钉钉风格的 HTML 结构 / 远程图片引用 | 采用纯文本副本，未恢复图片 |
| 分别复制文字、独立 PNG、文字，并依次粘贴 | 输入框保留可编辑前后文字与中间表格图片 |

这是 v0.1 网页分段方案的历史测试；v0.2 网页默认标准图文，桌面版使用下述原生完整图文方案。这个结果只验证了当次 Chrome 与钉钉的输入框，不代表一次复制混排已修复，也不代表已验证消息发送或所有平台。测试草稿已清理。版本号未记录。

## 2026-10-16 桌面版 → macOS 钉钉输入框实测

- Electron 44.8.0，macOS Apple Silicon，本地打包后的 md2chat 应用。
- 原生剪贴板读写往返测试通过：纯文字、HTML、`com.dingtalk.richTextAttributedString` 同时保留；JSON 内容与输入一致。
- 使用不含工作信息的苹果/杯子表格样本：**应用点击一次复制，钉钉按一次 ⌘V，前文、表格图片和后文同时显示，文字保持可编辑。**
- 只在自己的聊天输入框测试，没有发送消息；草稿已清理。钉钉版本号未记录，不能泛化到所有版本。
- 微信、Windows、Intel Mac 和消息发送后的最终效果尚未完成同等验证。原生结构是观察到的私有协议，可能随钉钉升级变化。
- 复制用图片写入本机缓存，退出应用后保留以免剪贴板引用失效。超过 7 天后启动清理；剪贴板含钉钉格式时暂缓清理。
- 发布包为未签名/未公证的测试版，打包成功不代表已经完成正式分发认证。

## v0.5 目标平台入口

- 钉钉：仅 macOS 桌面写入钉钉专用结构；Windows / 网页仍是标准图文。
- 微信、飞书、企微：独立入口，使用同一标准 HTML 图文协议，不伪造未验证的客户端专用格式，也不附带钉钉原生数据。普通文字、图片顺序保持，图片为内嵌 PNG。
- 邮件：标准 HTML 和纯文本，表格保留可编辑单元格与内联样式。代码、公式、图表仍为图片。邮件 data URI 图片可能被编辑器或收件端移除，尚未实现 CID 附件邮件。
- 飞书、企微、邮件标为实验性，未安装客户端时仅验证格式生成和顺序，不能宣称粘贴或收件验收通过。
- 主界面不再提供分段复制按钮，不把整段文字转成 PNG。剪贴板排查继续保留。
