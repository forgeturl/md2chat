# v0.6.6

- Mac 桌面版飞书复制新增原生图文格式，支持按原顺序组合可编辑文字与多张图片，保留粗体、斜体和删除线。粘贴前请先展开飞书富文本输入框，普通输入框可能丢图。
- 主窗口与托盘“飞书格式”使用同一复制流程，补充展开输入框的操作提示。复制用图片缓存在本机，保护仍被剪贴板引用的缓存；无需配置飞书账号，不自动发送消息。
- 新增飞书原生数据编码、平台隔离、图片缓存、失败恢复和剪贴板往返回归测试，同步使用说明与平台指南。网页和 Windows 飞书仍使用实验性标准图文，兼容范围不外推到所有客户端版本。

# v0.6.5

- Windows 钉钉恢复 HTML 与纯文本并存，修正 0.6.4 缺少纯文本回退的问题。一次粘贴完整图文尚未解决，图片占位不代表图片已导入。
- Windows 增加可选“钉钉分段复制（备用）”，按顺序分别复制可编辑文字和独立 PNG；Mac 钉钉仍使用原生图文格式。
- 剪贴板排查新增无图片 HTML 文字测试与当前 HTML 文档重写测试，明确提示会替换剪贴板，不上传或保存 HTML。报告澄清解码 HTML 的片段标记不能证明原生 CF_HTML 头是否有效。
- 新增 Windows 真实 Electron 剪贴板验证、独立 Win32 CF_HTML 探针与打包前门禁，覆盖九类复制及回读用例，并上传脱敏逐项报告、人工样例与结果模板。CI 通过不等于钉钉客户端粘贴通过。

# v0.6.4

- 尝试改善 Windows 钉钉图文粘贴：含图时仅写 HTML，文字与图片使用段落结构，避免退回含「[图片]」的纯文本副本；纯文字复制和 Mac 钉钉原生图文保持原有方式。
- Windows 复制时保留原图已有的合规 HTTPS 来源；表格、代码、公式和图表生成的图片使用本机缓存引用，不自动上传图片。Windows 客户端是否成功导入仍需实测。
- 保留 Windows 当前剪贴板引用所需的缓存，旧图改为在下一次成功复制钉钉内容后清理；编辑器与托盘再导入时只回读本应用缓存内通过校验的 PNG，不开放任意本地文件读取。
- 新增 Windows 复制格式、两图顺序、HTTPS 来源、缓存往返与平台隔离的回归测试。本次是依据用户样本的兼容修复，尚未完成 Windows 钉钉真机验收；请使用内置读书会样本粘贴后核对两张图片。

# v0.6.3

- 增强剪贴板排查：桌面读取和手动粘贴样本均可显示图片引用类型、尺寸、脱敏属性名、附近标签和 HTML 片段标记；内嵌图片额外显示 MIME、base64 标记与数据字节数，便于对比 Windows 钉钉复制的图文。
- Windows 的 Mac 钉钉专用格式图片数改为「不适用」，并注明「最近复制目标」不代表当前剪贴板来源，避免将统计值误判为图片缺失。
- 排查不执行 HTML、不请求图片，报告不包含正文、完整链接、文件路径或属性值；读取失败和超限会明确提示，可一次复制最近两份脱敏报告。
- 已通过自动化测试和使用模拟 Windows 数据的浏览器界面验证。本版提供 Windows 钉钉进一步采样能力，实际图文粘贴兼容性仍待 Windows 客户端验证。

# v0.6.2

- 官网随正式版本发布：安装包与官网从同一版本标签构建，全部构建成功后发布 Release，再部署官网。

## v0.6.1

- Mac 使用一个 Universal 安装包，同时包含 Apple Silicon 和 Intel 架构；保留通用 ZIP 供应用内更新。
- 公证票据下载遇到临时网络错误时自动重试；签名、公证与 Gatekeeper 检查仍须全部通过。
- Actions 为每个工作流保留最近 10 次运行，临时构建产物保留 3 天。

- 任务列表改用 ✅ / ⬜ emoji，聊天、邮件和企微分段输出保持一致，普通文字仍可编辑。
- 官网补充 DeepSeek、Codex、Cursor 等 AI 回答转聊天图文的使用场景与官方资料说明；用当前桌面版重拍真实截图，并在首屏叠放展示转换前后效果。

- 代码图片改为 GitHub 浅色风格：浅灰底、细边框和清晰等宽字体，移除厚重标题栏与行号，收窄长行排版；复制时保留高清图片的正确显示宽度。
- 桌面工作台采用新的浅色界面：输入与预览置顶，品牌、说明、剪贴板排查、GitHub 和更新入口统一收到底栏，平台复制移至预览底部；小窗口保持双栏，手机端上下排列。
- 企微图文改为分段复制，网页和桌面均按顺序分别复制纯文字与 PNG，避免整段粘贴时只剩文字或图片。纯文字仍可直接复制；文字可编辑，强调样式不保证保留。
- 托盘「剪贴板转换」子菜单第一项为「转图片」，位于「微信格式」等平台格式之前，可将剪贴板图文排成一张 PNG 后复制。
- 托盘「首选项」改为独立设置窗口。「托盘常用格式」支持多选，可拖动或使用上移、下移调整菜单顶部入口的顺序，并可配置开机自启动。设置立即生效并保存在本机。
- 托盘使用更醒目的专用图标，默认不显示应用名；Mac 可在首选项开启名称显示。「显示主窗口」移至「首选项」上方。「帮助 ↗」直接打开 GitHub Issues，「检查更新」保留独立入口。
- 托盘及子菜单增加彩色图标，微信、钉钉、飞书、企业微信使用经官网核实的标识，并同步提供高清屏图标；邮件使用通用信封图标。
- 托盘「企业微信格式」遇到图文时打开独立分段面板，保留主编辑器已有内容，打开面板时不写回整段混合格式。
- 已在 macOS Apple Silicon、企业微信 5.0.12（70798）自己的文件传输助手草稿中完成新版分段面板实测：网页 5 段含 2 张图片、桌面 3 段含 1 张图片，文字保持可编辑；未发送消息。Windows 企微和发送后效果未验证。

## 更新与平台复制

- 网页版禁用钉钉复制，仅在悬浮或键盘聚焦钉钉按钮时显示桌面版下载入口；桌面版钉钉复制保持可用。
- 点击平台图标复制后，醒目提示「已复制到剪贴板」及粘贴目标；失败时显示错误提示。
- 新增桌面应用内更新：检查新版本、展示更新说明，点击下载后显示进度，再确认重启安装。
- 启动后及每 6 小时检查稳定版更新；可在主窗口、帮助菜单或托盘菜单手动检查。
- 不自动下载，不在普通退出时自动安装。安装前提醒保存输入，更新请求不包含正文。
- Mac 发布必须通过 Developer ID 签名与 Apple 公证；Windows 使用 NSIS 更新安装器，目前 Windows 未签名。
- Mac 改为通用安装包，同一个 DMG 包含 M 系列和 Intel 两种架构，无需选择芯片类型；保留通用 ZIP 供应用内更新，同时发布 Windows x64 安装包及校验过的更新清单。

0.5.1 及更早版本尚无应用内更新，请手动安装本版一次。Mac 请将应用放入「应用程序」。后续升级需要使用同一开发者团队签名。

客户端兼容范围维持原有说明：Mac 钉钉原生图文已在 M 系列输入框实测；Intel Mac、Windows 钉钉和其他聊天客户端仍需分别验收，不能以通用包构建成功替代运行与粘贴验证。
