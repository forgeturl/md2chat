md2chat 首个 macOS 桌面测试版（Apple Silicon / M 系列）。

- 复用左右栏 Markdown 编辑与预览。
- 原生图文复制：可编辑文字 + 图片 + 文字，一次复制到钉钉输入框。
- 支持表格、彩色代码块、数学公式、Mermaid 转图片。
- 不需要浏览器插件或独立助手，不上传正文和图片。
- 提供系统剪贴板元数据排查，不在报告中暴露正文或图片地址。

验证：macOS Apple Silicon 上运行打包应用，复制虚构的前文、表格、后文，按一次 ⌘V 粘贴到钉钉自己的输入框，文字和图片同时显示。未发送消息，测试草稿已清理。微信、Windows 和其他客户端未完成同等验证。

**当前安装包尚未进行 Apple 开发者签名和公证，macOS 可能阻止打开。需要无阻碍安装的用户请等待正式签名版。** 此发布标记为预发布，不代表已完成正式分发认证。ZIP 是同一应用的归档，DMG 用于安装。SHA256SUMS.txt 提供文件校验值。

正文不持久保存。复制所需图片缓存在应用本机目录；超过 7 天后启动时清理，当前剪贴板含钉钉专有格式时暂缓清理。远程图片会请求图片原网址。退出应用不会立即清除仍用于粘贴的图片。

帮助菜单可打开版本下载页；本版不会静默下载或安装更新。钉钉专有格式并非公开稳定接口，升级客户端后可能需要适配。
