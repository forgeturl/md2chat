## 自启动与安装

请先安装应用后再配置，开发模式不注册启动项。macOS 应用请放入「应用程序」。当前包尚未完成开发者签名与 Apple 公证，可能被系统阻止打开，也可能无法成功注册自启动；需要系统批准或注册未生效时会提示。Windows 安装包也尚未签名。

开机自启动状态从系统读取，应用不会自行打开此设置。关闭窗口仅隐藏，正文保留在内存；退出后不会恢复正文。图片缓存仍按原来的 7 天策略清理。

## 验证范围

自动检查覆盖 Windows 启动参数、系统禁用状态、macOS 待批准状态、开发模式禁用注册、托盘菜单及失败退路。Windows 托盘和自启动仍需真机验收，未进行实际重启验证。

macOS 钉钉原生图文此前已在 M 系列 Mac 输入框实测。Windows 使用标准 HTML 图文，尚未适配 Windows 钉钉专有格式，可能丢图。应用不会自动发送消息，也不会后台自动安装更新。

下载：Windows 使用 `md2chat-windows-x64-setup.exe`；Mac 按芯片选择 `md2chat-mac-arm64.dmg` 或 `md2chat-mac-x64.dmg`。另有 ZIP 和 `SHA256SUMS.txt` 校验文件。
