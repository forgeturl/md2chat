# v0.6.0

- 任务列表改用 ✅ / ⬜ emoji，聊天、邮件和企微分段输出保持一致，普通文字仍可编辑。
- 官网补充 DeepSeek、Codex、Cursor 等 AI 回答转聊天图文的使用场景与官方资料说明；用当前桌面版重拍真实截图，并在首屏叠放展示转换前后效果。

- 代码图片改为 GitHub 浅色风格：浅灰底、细边框和清晰等宽字体，移除厚重标题栏与行号，收窄长行排版；复制时保留高清图片的正确显示宽度。
- 桌面工作台采用新的浅色界面：输入与预览置顶，品牌、说明、剪贴板排查、GitHub 和更新入口统一收到底栏，平台复制移至预览底部；小窗口保持双栏，手机端上下排列。
- 企微图文改为分段复制，网页和桌面均按顺序分别复制纯文字与 PNG，避免整段粘贴时只剩文字或图片。纯文字仍可直接复制；文字可编辑，强调样式不保证保留。
- 托盘「剪贴板转换」子菜单第一项为「转图片」，位于「微信格式」等平台格式之前，可将剪贴板图文排成一张 PNG 后复制。
- 托盘「首选项」改为独立设置窗口。「托盘常用格式」支持多选，可拖动或使用上移、下移调整菜单顶部入口的顺序，并可配置开机自启动。设置立即生效并保存在本机。
- 托盘使用更醒目的专用图标，默认不显示应用名；Mac 可在首选项开启名称显示。「显示主窗口」移至「首选项」上方。「帮助 ↗」直接打开 GitHub Issues，「检查更新」保留独立入口。
- 托盘及子菜单增加彩色图标，微信、钉钉、飞书、企业微信使用经官网核实的标识，并同步提供高清屏图标；邮件使用通用信封图标。
- 托盘「企业微信格式」遇到图文时打开独立分段面板，保留主编辑器已有内容，打开面板时不写回整段混合格式。
- 已在 macOS Apple Silicon、企业微信 5.0.12（70798）自己的文件传输助手草稿中完成新版分段面板实测：网页 5 段含 2 张图片、桌面 3 段含 1 张图片，文字保持可编辑；未发送消息。Windows 企微和发送后效果未验证。

## 更新与平台复制

- 网页版禁用钉钉复制，仅在悬浮或键盘聚焦钉钉按钮时显示桌面版下载入口；桌面版钉钉复制保持可用。
- 点击平台图标复制后，醒目提示「已复制到剪贴板」及粘贴目标；失败时显示错误提示。
- 新增桌面应用内更新：检查新版本、展示更新说明，点击下载后显示进度，再确认重启安装。
- 启动后及每 6 小时检查稳定版更新；可在主窗口、帮助菜单或托盘菜单手动检查。
- 不自动下载，不在普通退出时自动安装。安装前提醒保存输入，更新请求不包含正文。
- Mac 发布必须通过 Developer ID 签名与 Apple 公证；Windows 使用 NSIS 更新安装器，目前 Windows 未签名。
- 同时发布 M 系列、Intel Mac 和 Windows x64 的安装包及校验过的更新清单。

0.5.1 及更早版本尚无应用内更新，请手动安装本版一次。Mac 请将应用放入「应用程序」。后续升级需要使用同一开发者团队签名。

客户端兼容范围维持原有说明：Mac 钉钉原生图文已在 M 系列输入框实测；Windows 钉钉、其他聊天客户端仍需分别验收，不能以构建成功替代粘贴验证。
