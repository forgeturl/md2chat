## डाउनलोड

- [macOS Universal DMG — Apple Silicon और Intel](https://github.com/forgeturl/md2chat/releases/latest/download/md2chat-mac-universal.dmg)
- [Windows x64 इंस्टॉलर — Intel और AMD](https://github.com/forgeturl/md2chat/releases/latest/download/md2chat-windows-x64-setup.exe)

ये लिंक हमेशा नवीनतम रिलीज़ खोलते हैं। Mac पर सामान्य इंस्टॉल के लिए DMG लें; `.app.tar.gz` ऐप के अंदर अपडेट के लिए है। Windows ARM का मूल पैकेज उपलब्ध नहीं है। डेस्कटॉप Tauri 2, Rust और सिस्टम WebView इस्तेमाल करता है; Electron या Node.js शामिल नहीं हैं। Windows इंस्टॉलर ज़रूरत होने पर WebView2 डाउनलोड करता है। आधिकारिक Mac रिलीज़ के लिए Developer ID हस्ताक्षर और नोटरीकरण चाहिए; Windows में अभी Authenticode हस्ताक्षर नहीं है। पुराने Electron इंस्टॉल का अपने आप स्थानांतरण नहीं होता।

## उपयोग

बाईं ओर Markdown, टेक्स्ट या चित्र पेस्ट करें, पूर्वावलोकन देखें, गंतव्य चुनें और उस ऐप में पेस्ट करें। साफ़ करने पर खाली दस्तावेज़ मिलता है। वेब में DingTalk और Feishu कॉपी बंद है; इनके लिए डेस्कटॉप ऐप लें।

- **WeChat:** सामान्य टेक्स्ट और चित्र; सुनिश्चित करें कि सभी चित्र बने रहें।
- **DingTalk:** Mac पर मूल प्रारूप, Windows पर HTML और सामान्य टेक्स्ट विकल्प। पुराने Mac परीक्षण हर मौजूदा संस्करण को सत्यापित नहीं करते; Windows में वास्तविक ऐप जाँच बाकी है।
- **Feishu/Lark:** Mac पर पहले समृद्ध पाठ इनपुट खोलें। Mac में टेक्स्ट-चित्र मिश्रण और भेजने का परीक्षण हुआ है; Windows अभी प्रयोगात्मक है।
- **WeCom:** Mac और Windows पर टेक्स्ट व चित्र एक साथ पेस्ट होते हैं; वेब पर क्रम से खंड पेस्ट करें। Windows 5.0.12.6018 के फ़ॉर्मैट परीक्षण में दो चित्र, चीनी पाठ और क्रमांक रहे, लेकिन बोल्ड, फ़ॉन्ट आकार और रंग हट गए। फ़ाइल ट्रांसफ़र असिस्टेंट में भेजे गए परीक्षण भी सफल रहे; नए Windows बिल्ड का सत्यापन बाकी है।
- **ईमेल:** संपादन योग्य HTML तालिकाएँ; जटिल सामग्री चित्र बनती है। यह प्रयोगात्मक है: पेस्ट और भेजने के बाद चित्र जाँचें।

डेस्कटॉप पूरे दस्तावेज़ को सफ़ेद पृष्ठभूमि वाले एक PNG में भी बदल सकता है। उसके अंदर का टेक्स्ट संपादन योग्य नहीं है। लंबी सामग्री छोटी की जा सकती है या सीमा पार होने पर अस्वीकार हो सकती है। रूपांतरण के दौरान क्लिपबोर्ड बदलने पर नया डेटा सुरक्षित रहता है और दोबारा कोशिश का संदेश मिलता है। सत्यापन के बाद स्थानीय पूर्ण पथ और `file:///` चित्र समर्थित हैं: PNG, JPEG, GIF, WebP या BMP, प्रति चित्र 10 MB और 2 करोड़ पिक्सेल तक। वेब पर सीधे चित्र पेस्ट करें। संदेश अपने आप नहीं भेजे जाते।

## ट्रे और शॉर्टकट

Mac मेनू बार या Windows ट्रे से संपादक बदले बिना क्लिपबोर्ड बदलें, विंडो और प्राथमिकताएँ खोलें, अपडेट जाँचें या पूरी तरह बंद करें। विंडो बंद करने पर प्रक्रिया और इनपुट मेमोरी में रहते हैं। प्राथमिकताओं में प्रारूप पिन और क्रमबद्ध कर सकते हैं, लॉगिन पर शुरू करना और वैश्विक रूपांतरण शॉर्टकट सेट कर सकते हैं। दोनों को स्पष्ट रूप से चालू करना होता है। Mac में ऐप Applications में इंस्टॉल करें। Windows ट्रे और अपने आप शुरू होने की वास्तविक डिवाइस जाँच बाकी है।

## भाषाएँ और अपडेट

इंटरफ़ेस, अंतर्निहित उदाहरण, वेबसाइट, README और अपडेट सार नौ भाषाओं में उपलब्ध हैं। ग्लोब मेनू में भाषाओं के अपने नाम दिखते हैं। बिना बदले उदाहरण भाषा के साथ बदलते हैं; संपादन, पेस्ट, ड्रॉप या साफ़ करने के बाद उपयोगकर्ता की सामग्री बनी रहती है, वापस पूर्ववत करने पर भी।

अपडेट सार में इंस्टॉल किए संस्करण के बाद से लक्ष्य संस्करण तक की प्रकाशित रिलीज़ दिखती हैं। हाल की तीन पहले दिखती हैं; पुरानी खोल सकते हैं और ज़रूरी सूचनाएँ हमेशा दिखती हैं। तकनीकी विवरण मूल भाषा में रहते हैं। शुरू होने के बाद और हर छह घंटे में अपडेट जाँचे जाते हैं; डाउनलोड और पुनः शुरू करना उपयोगकर्ता के हाथ में है। इंस्टॉल से पहले सामग्री सहेजें। पुराने क्लाइंट को नया इंटरफ़ेस संबंधित संस्करण इंस्टॉल करने के बाद मिलता है; वास्तविक संस्करण परिवर्तन की जाँच हस्ताक्षरित पैकेज से करनी होती है।

पुराने अपडेट के सार चुनी हुई भाषा और अपग्रेड सीमा के अनुसार लोड और कैश होते हैं। विफलता पर वर्तमान सार दिखता रहता है और इंस्टॉलर डाउनलोड कर सकते हैं। फिर कोशिश करने के लिए विंडो बंद करके दोबारा खोलें; सफलतापूर्वक लोड हुआ इतिहास कैश से दोबारा इस्तेमाल होता है। पुराने क्लाइंट संगत `notes` फ़ील्ड पढ़ते रहते हैं।

## गोपनीयता और जाँच

खाते की ज़रूरत नहीं और सामग्री md2chat सेवा पर अपलोड नहीं होती। रूपांतरण स्थानीय है। दूरस्थ चित्र अपने मूल सर्वर से जुड़ते हैं; बाद में पेस्ट करने के लिए डेस्कटॉप चित्र स्थानीय कैश में रख सकता है। इनपुट स्थायी रूप से नहीं सहेजा जाता; पूरी तरह बंद करने या दोबारा लोड करने पर मिट जाता है।

क्लिपबोर्ड जाँच केवल अनुरोध पर पढ़ती है। निर्यात ZIP में मूल टेक्स्ट, चित्र, लिंक और निजी प्रारूप हो सकते हैं: साझा करने से पहले जाँचें। जाँच बंद करने पर नमूना मिटता है। अपने आप अपलोड नहीं होता; Issue लिंक GitHub खोलता है जहाँ ZIP स्वयं जोड़ें। अपडेट अनुरोध में दस्तावेज़ की सामग्री नहीं होती।

## विकास

Node.js 22.12+ और Rust 1.90+ चाहिए। Mac पर Xcode Command Line Tools; Windows पर Visual Studio C++ उपकरण और WebView2 चाहिए। पैकेज उसी OS पर बनाएँ। आधिकारिक Mac DMG के लिए Python 3.10+ और `scripts/dmgbuild-requirements.txt` में हैश से तय निर्भरताएँ भी चाहिए।

```sh
npm ci
npm run dev
npm run desktop
npm run check
npm run build
npm run desktop:test
npm run desktop:test:render
npm run desktop:test:native
npm run desktop:test:windows
npm run desktop:dist:mac
npm run desktop:dist:win
```

मूल क्लिपबोर्ड परीक्षण थोड़ी देर के लिए क्लिपबोर्ड बदलकर उसे बहाल करते हैं; उपयोग न हो तब चलाएँ। वेब और प्रारूप परीक्षण वास्तविक चैट ऐप की स्वीकृति सिद्ध नहीं करते। सीमित डेस्कटॉप कमांड केवल बंडल किए स्थानीय पृष्ठ चला सकते हैं; WebView Node.js उपलब्ध नहीं कराता।

## योगदान और रिलीज़

हर दिखाई देने वाले बदलाव में [बहुभाषी रखरखाव नियम](../localization.md) के अनुसार नौ भाषाएँ साथ अपडेट करें। पृष्ठ या संसाधन बदलने के बाद `npm run seo:generate` और कमिट से पहले `npm run check` चलाएँ। अनुवादित साइट स्रोत `site/locales/` में हैं; सार्वजनिक URL पहले जैसे रहते हैं। इस निर्देशिका में README के आठ अनुवाद हैं; मुख्य README चीनी में है। तकनीकी रिकॉर्ड मूल भाषा में हो सकते हैं।

विस्तृत विवरण और नौ भाषाओं का सार तैयार करें:

```sh
npm run release:prepare -- patch --notes-file /tmp/md2chat-release-notes.md --summary-file /tmp/md2chat-update-summary.json
npm run release:verify -- --tag vX.Y.Z
```

फ़ाइलों और जाँच की समीक्षा करें, फिर `npm run release:verify -- --tag vX.Y.Z` चलाएँ। तैयारी अपने आप कमिट या प्रकाशित नहीं करती। स्पष्ट रिलीज़ अनुरोध पर ही संस्करण टैग बनाएँ और पुश करें। main या PR रिलीज़ नहीं करते; केवल वेबसाइट के लिए अलग कार्यप्रवाह है। आधिकारिक रिलीज़ पैकेज और हस्ताक्षर सत्यापित करके GitHub Release और उसी संस्करण की वेबसाइट प्रकाशित करती है। मैन्युअल डेस्कटॉप कार्यप्रवाह केवल परीक्षण पैकेज बनाता है, ऐप अपडेट या प्रकाशन नहीं। [हस्ताक्षर और रिलीज़](../auto-update.md), [सार नीति](../update-summaries.md), [Windows जाँच](../windows-clipboard-qa.md) और [विस्तृत रखरखाव संदर्भ](../../README.md#发布) देखें।
